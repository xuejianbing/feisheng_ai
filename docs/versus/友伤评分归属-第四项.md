# 2v2 旧友伤公式与评分归属：第四项

[weique | 2026-10-20] 本地候选修复；尚未进行2v2真实对局或联机验证。

## 问题与处理

旧 VERSUS_STRATEGY.decisionBoost 对友方伤害先扣2分，再以“敌方获得奖励”为由加回当前动作分。加回量还取决于队友当前体力，而不是实际损失：例如队友三血、有敌人存活时，原模式增量为 −2 + 1 = −1；敌人离场后反而变回 −2。它并没有把分数转给敌方。

普通2v2现有链路已经包含：

1. 单目标伤友的 actionDirectionGuard 上限，不因模型把基础分抬高而放行。
2. 全场南蛮、万箭的 areaExpectedValue，计算友方损失和濒死 / 救援额外风险。

因此此次没有把错误的加号机械改成减号，而是让 versus/two、versus/2v2 普通规则退出整段旧友伤公式。modeStrategy 不再为伤友追加固定模式分，也不返还“敌方奖励”。敌方攻击与友方救援的既有模式偏好保留。

## 实际评分例子

- 对队友出杀，进入模式建议前4分：模式层保持4分，随后原方向护栏压到 −8；模式层返回0不代表动作允许执行。
- 同一伤友候选原本 −12：不因旧模式公式再扣一笔，护栏也不把它重复压低，仍为 −12。
- 对自己使用火攻的已有正收益候选：模式层不再把 self 当队友套固定罚分；仍受原有合法性、成本与安全检查，不额外赠送分数。
- 无单目标绑定的群体牌：沿用统一 AOE 收益，模式层不另算一份友伤成本。

普通伤友动作在既有护栏后的排序可能与修复前相同。这一项主要消除错误返还与重复评分，不宣称所有出牌选择都会改变。

## 边界

- 本轮未修改 actionDirectionGuard、宿主伤害效果或具体配合评估器。不会仅因武将有“卖血技能”、宿主 effect 为正或调用者给出高分就新增友伤豁免；现有关系护栏对普通伤友的限制继续保留。完整的队友卖血配合仍是独立议题。
- 不读取队友隐藏手牌，也不再依赖 identity / identityShown 或敌方人数来计算普通2v2伤友模式分。
- 该修复不受 tacticalOptimization 开关控制，关闭增强也不重新启用错误公式。
- 3v3、4v4、四国和自定义乱斗等其他对决路径保留旧兼容行为；它们的旧公式未在本轮修复。
- 选将、模型、训练、权重和界面按钮未改动；未执行 commit、push 或创建PR。
