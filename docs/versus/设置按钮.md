# 2v2 设置按钮

玩家选项 → 03 · 模式增强 → 2v2，与斗地主共用折叠栏、原生开关和查看按钮样式。

- 2v2策略增强：默认开启；控制下面两个分项。关闭时分项变灰，保留原值。
- 座次配合与队友保护：默认开启；控制座次机会、接力拆甲和群体牌队友风险。
- 关键牌保留：默认开启；控制普通牌成本、弃牌保留和主动技能材料保留。
- 专项状态：始终可查看，说明当前模式是否适用，以及分项关闭的原因。

设置列表只显示名称，不显示策略说明。细节集中在专项状态中。

仅适用于欢乐2v2和联机2v2；自定义乱斗不自动适用。专项优化仍受开发者选项中的通用打法优化开关控制。状态页同时说明该依赖。

基础阵营、合法目标与伤害判断不受专项开关控制。修改用于后续判断，不保证已经开始的选择重新评分。
