# 2v2 设置说明

设置入口：**玩家选项 → 03 · 模式增强 → 2v2**。

- **2v2策略增强：** 总开关。关闭后，下面两项会暂时停用，原来的开关状态会保留。
- **座次配合与队友保护：** 调整队友保护、接力拆防具和群体牌风险判断。
- **关键牌保留：** 让 AI 在用牌或弃牌时考虑桃、闪、无懈等牌后续可能的用途。
- **专项状态：** 查看当前对局是否适用这些设置，以及未生效的原因。

这些设置适用于欢乐2v2和联机2v2，不自动用于自定义乱斗。专项策略还需要通用“打法优化”开关处于开启状态。

基础的队伍识别、合法目标和伤害判断不受上述开关影响。修改设置后会用于接下来的判断；已经打开的出牌选择不会重新计算。
