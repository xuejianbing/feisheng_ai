# 2v2 座次协作：第一项

[weique | 2026-10-20] 本地候选实现，尚未真实对局验证。选将暂停；不涉及训练模型和权重。

## 这次做什么

仅在 versus/two、versus/2v2 的普通规则接入路径工作。队伍依据公开 side，计划依据宿主常规行动环；自定义乱斗不自动纳入。新增座次机会判断使用现有 tacticalOptimization 开关，接力拆顺同时遵守 tacticalStrip。没有新建设置页。

### 14 队的一号位

一号行动后，队友四号之前有二号、三号两个敌方回合。但不能把“敌方即将行动”直接当作“能攻击四号”：无装备和技能修正、攻击距离为 1 时，二号到四号距离为 2，三号到四号距离为 1。

四号体力不高于 2，且有敌人在其行动前具备公开攻击可达性时，团队计划提示保护。已有合法、正收益的乐 / 兵候选，如果针对这些敌人，可获得 0.15 的座次偏好；两个可达威胁时封顶 0.3。它不是伤害概率，也不保证判定成功。此项不增加一份基础救援或击杀收益。

### 23 队的二号位

三号紧接二号行动时，考虑接力机会：

- 两人都具备公开攻击距离的敌人，可以给已有正收益、合法的单目标攻击候选补 0.15 的机会偏好。
- 二号有合法过河、四号有可拆且正价值的防具、三号当前能到达四号时，可以使用接力拆防具计划，即使二号自己没有杀。
- 接力计划同时进入既有宿主 effect 和拆顺按钮选择，实际选择同一防具；目标变化或防具消失后重算。
- 距离为 2 的顺手仍不可使用。队友翻面、已知跳出牌阶段、濒死或打不到目标时，不给接力机会。

拆顺继续优先保留原有自己的后续攻击计划和延时锦囊配合。新增接力只在这些计划未给出具体选择时补充；宿主 effect 只补 0.2 的机会信号，不再次计算整件装备收益，也不套用自己已有杀时的 order=13 强顺序。其他评分层不再给同一拆顺追加座次分。

### 四号到下一轮一号

同样按实际常规行动环判断。如果四号之后是一号队友，就与二号到三号采用相同机制；不依赖显示编号写死。

## 计划如何更新

2v2 绕过原团队计划中仅按自己血量、手牌数量、轮次建立的缓存。每次读取重新检查队友血量、死亡、座次、距离和当前行动者。

例如三号阵亡后，二号与四号距离可能缩短，因此不能只删除三号的威胁而继续沿用二号“打不到”的旧结论。两人都能到达多个敌人时，不随意把第一个指定为唯一集火目标；继续让现有动作净收益比较。

## 开局不再统一攒牌

2v2 早期的公共进攻、保留、爆发阶段倍率改为 1；多轮策略不再套用“决斗 0.7、无中 / 五谷 1.3”的统一早期偏好。并非强制开局进攻，而是让具体动作收益与合法性决定。其他模式保持原逻辑。

## 执行与信息边界

- 新增动作偏好只在当前行动者自己的出牌阶段结算；响应、摸牌阶段不追加。
- 候选必须合法、可用、明确单目标、原本正分，且宿主评估为正收益；受禁、未绑定目标、非正收益、友伤、AOE、结束回合不因此被抬分。
- 独占来源 versusSeatTempo，一次候选只记一次，保留方向与执行护栏。
- 只读取行动者自己的手牌和他人公开状态。队友能到达不代表其有杀，不读取队友隐藏手牌。
- 行动环描述常规机会，额外回合和技能插队后的实际下一行动者仍由宿主决定。
- 没有新增自动选将、专用留桃算法、跨回合确定性连招或完整救援决策。这些后续分项实现。
