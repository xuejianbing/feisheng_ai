# 实体攻击选择衔接

[weique | 2026-10-23] 待发布，未进行真实对局验证。

## 本次修改

前面的牌名候选用同名实体牌中的较好机会评分，但宿主最终选择并未消费逐牌估值。本次在实际 `ai.basic.chooseCard` 与 `chooseTarget` 的 check 入口重新评估，不缓存或强制锁定先前牌对象。

- 选牌使用正在评分的实体牌，在当前合法敌方目标中评估攻击机会。
- 选目标使用唯一已选实体牌，重新核对伤害、护甲、防具、距离及宿主目标筛选。
- 读取宿主公开属性修正；默认目标数量按实体牌信息与公开技能修正核对，不借用尚未选中的另一张牌。
- 原生非正分及非有限分保持原样；支持的正分攻击候选使用同一攻击估值，不再重复追加伤害或斩杀加分。
- 不修改真实牌、目标、filterCard或filterTarget；原生最终合法性检查继续负责执行。
- 手动／远端玩家不接管；换局、结束、切换事件和卸载使旧回调失效。

## 例子

对方装备仁王盾，自己有黑杀和红杀：黑杀按自身颜色评估为无伤害机会，红杀按自身效果评估。若已选黑杀，再选目标时不会借用手中另一张红杀对仁王盾目标的收益。

对方装备藤甲时，普通杀和火属性杀分别评估；宿主公开修改属性后也重新读取，不沿用先前属性。

## 范围与限制

仅覆盖直接主动、单张实体手牌、单目标的杀及决斗。转化技能、强制或响应、多牌、多目标、复杂选择和不能确认用途的自定义范围均保留原生判断；本次不扩展技能材料成本覆盖。斩杀仍为启发式机会估计，不保证必杀或胜率。

本项属于实际攻击判断衔接，不随座次或留牌策略开关关闭；随引擎安装卸载。不处理暂停中的特殊行动顺序审查或实际对局验证。
