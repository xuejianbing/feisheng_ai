## 二、合并方法

三方合并（`git merge-file`），以 master 为 ours、`d3dbad6`（4.1.4.0）为 base、QA 包为 theirs：

1. 先做 **LF 归一**（QA 包为 CRLF、仓库为 LF，直接合并会产生整文件级冲突）；
2. 45 个文件自动合并成功（双方改动位于不同区域）；
3. `score/foundation/cloud/cloudIngest.js` 存在 3 处结构性冲突——QA 线把它重写为「写前日志 + 回执确认 + 来源信封」模式，与我们的 `shadowPolicy` 通道冲突；
   **决定采用 QA 重写版**（来源认证后端必需），`shadowPolicy` 上传通道让位：
   v3 影子记录仍在本地队列 `djsc_shadow_v3_pending` 中，暂不随上传。
4. 合并后在 master 上执行 `git merge -s ours release/4.4.0`，记录分支祖先关系，保留统一树。
