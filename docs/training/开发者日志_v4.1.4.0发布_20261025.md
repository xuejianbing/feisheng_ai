### 9.3 踩坑记录：Release asset 上传端点

上传 Release asset 时，标准的 `POST https://api.github.com/repos/{owner}/{repo}/releases/{id}/assets?name=...` 在当前凭证下**恒返回 404**（小文件与完整包均如此，且 `GET` 同一 release / `GET` assets 列表均 200，权限为 admin，排除权限与路径问题）。

实际可用端点是 **`https://uploads.github.com/repos/{owner}/{repo}/releases/{id}/assets?name=...`**，上传返回 201。

### 9.4 踩坑记录：无人值守批量跑 `tools/*.mjs`

用 glob 批量执行 `tools/` 下全部 `.mjs` 时，`run-ui-lab.mjs`（需要人工交互的 UI 实验台）会**无限挂起**，导致整批测试超时；`export-weights.mjs` 因缺少必填 CLI 参数退出码非 0，属预期用法。批量自检应使用**明确的测试脚本清单**，把工装脚本排除在外（本次清单 25 个，含 23 PASS / 2 playwright 缺失）。
