# 斗地主配合意图与决策衔接

本 PR 针对玩家主动配合被队友无懈、专项按钮的判断被后续通用规则覆盖，以及同一动作在评分与实际选择阶段采用不同依据的问题。基于 master 单独整理，不包含并行开发的 2v2 改动。原来的专项开关继续生效，没有新增设置按钮或更换模型权重。

## 最终行为与主要模块

| 范围 | 行为与依据 |
|---|---|
| 玩家操作意图 | 绑定实际 useCard 及正常人类选择窗口，覆盖火攻、铁索、拆顺、借刀、友方决斗；可防御、非致命的 AOE 只放宽响应者自身目标。托管、强制用牌、旧事件不取得同样权限。 |
| 无懈与反无懈 | 原生响应请求使用统一 evaluator，新旧响应桥消费同一意图。尊重玩家意图不会凭空产生反无懈收益，恢复锦囊仍需收益覆盖无懈成本。 |
| 拆顺 | 友方兵乐救援及受伤白银狮子净回复由同一公开计划贯通候选、方向、最终模型护栏、合法目标及实际选牌；不读取对手隐藏手牌。 |
| 借刀 | 持刀者与被杀者按有序组合保存和校验，主动计划与真实响应分开估计；持刀队友不再被当成被杀者，武器转移遵守原生可获得范围。 |
| 静态转化 | 识别实体响应及静态单/双材料转化，支持技能分组和布尔/对象/函数筛选；武圣、龙胆、丈八经过真实宿主结算。进入 skill.check 后的材料评分与借刀分支保持一致。 |
| 多次响应 | 从合法静态材料选项寻找足够多组不重叠组合，修复先选 AB 而漏掉 AC＋BD 的误判。单材料去重，双材料使用一般图匹配，支持奇数环，避免指数级组合搜索。 |
| 决斗与铁索 | 删除决斗比点及通用留杀的二次否决；删除旧铁索提示对其他牌目标的污染。原生合法性仍然优先。 |
| 缓存 | 两层决策缓存统一检查玩家对象、状态键、未结束的选择窗口、局次和事务；状态键补充公开护甲/翻面、自身可用技能/跳过阶段及实体手牌引用。 |
| 福利与延时锦囊 | 桃园、无中采用宿主实际效果，五谷只读取当前真实公开牌池；兵乐主动/无懈共享阶段损失估计，已知跳过阶段不重复计损失。 |
| 建议融合与对账 | 常规斗地主建议按显式理由去重并有界融合，保留零分候选与引用基准；重复基础收益不二加。详细诊断记录设置、早期评分、未采纳建议和真实执行状态，不额外调用模型。 |
| 人类选牌权 | 本机手动自火攻保留展示选择，连接中的远端玩家不注入自动展示回调；离线 AI 和本机托管保留原优化。 |

评分、合法性、policy 职责和模型排序保留各自责任。专项计划给出依据，不直接伪造玩家选择结果。完成、换局及卸载后意图凭据和旧回调失效。

## 更新日志与设置

- 仓库 `CHANGELOG.md` 的“待发布 · 斗地主配合意图与决策衔接”条目说明玩家可感知变化、原有按钮、生效时间、诊断入口和验证边界。

- 版本号及正式版本历史保持当前值；本条记录随 PR 提交，等待合并和后续整包发布。

## 独立分支验证

独立分支复核通过：17 组工具检查共 1014 项、Python 20 项、六个真实宿主固定场景、十个实际点击场景，以及正常开局的完整托管对局（6 个角色回合、30 次用牌、20 次引擎决策）。宿主报告中的浏览器脚本异常为 0。

下面的报告在本 PR 分支重新生成；此前共享工作区包含并行 2v2 的历史测试总数不作为本 PR 的验证数量。

- [工具回归汇总](verification/pr-isolated-regressions.json)：包含针对性边界、身份兼容及既有工具回归。材料匹配用两组各 32768 种配置与独立最优解对照，配置数量计入测试组，不另累加成数万项测试。
- Python：`python3 -m unittest discover -s tests -q`，20 项。
- 修改及新增脚本语法、相对导入完整性、`git diff --check`。
- [真实宿主固定场景](verification/pr-isolated-host-scenes.json)：低点数杀响应决斗、武圣/丈八/龙胆借刀、拆狮子回血、五谷公开池，共六个。
- [真实浏览器点击场景](verification/pr-isolated-manual-scenes.json)：九个本地手动输入及一个指定敌方进攻对照，详见下表。
- [完整托管对局](verification/pr-isolated-autoplay.json)：正常开局保留随机武将与原生结算，检查实际引擎参与并进入胜负结算；不把胜负本身作为策略强度结论。

### 本地手动输入验收

| 场景 | 验收结果 |
|---|---|
| 自火攻，新无懈优化开启/关闭 | 玩家点击牌、自己及同花色弃牌，自己掉 1 血；队友持有无懈且保留，记录意图被尊重。 |
| 友方决斗 | 队友无杀但有无懈，允许玩家操作，实际掉 1 血。 |
| 铁索自己与队友 | 两个目标均横置，无懈保留；两个目标关联同一次用牌。 |
| 拆友方白银狮子 | 玩家实际点选公开狮子，装备移除、队友回血，无懈保留。 |
| 玩家无懈自己的友方决斗 | 队友不凭意图盲目反无懈；决斗取消、没有伤害。 |
| 地主无懈玩家的进攻决斗 | 队友反无懈恢复，真实用牌顺序为地主无懈→队友无懈，最终地主掉血。 |
| 南蛮/万箭 | 队友保留无懈并实际使用杀/闪防御，队友无伤，地主掉血。 |
| 敌方火攻对照 | 指定敌方实际进攻，队友消耗无懈保护农民，不授予友方人工配合权限。 |

宿主验证使用隔离 Chrome 上下文和只读文件服务，屏蔽安装目录的用户配置与第三方扩展自动载入，阻止外部网络和文件写入，不覆盖已安装扩展或玩家存档。固定局面清理角色技能并安排确定的手牌/装备/公开身份，宿主 Player、GameEvent 和牌内容不由测试桩替换。手动场景通过 DOM 点击，不向事件注入选择结果。

为了测试玩家取消自己的牌，隔离上下文关闭原生“跳过无懈自己的牌”设置（wuxie_self=false）。旧响应桥读取真实请求已计算的结果，测试观察器不修改 AI 分数。敌方进攻对照使用指定进攻请求，不把敌方没有行动当成防护成功。


## 边界

- 本地实际点击不等同于真实双客户端联机；远端展示控制回归是生产模块宿主桩检查，消息传输、断线、托管切换尚未联机验收。
- 动态 viewAs、依赖已选材料、次数限制、未知额外 cost、特别失装收益仍保留原生回退。每技能枚举最多 128 组材料，未枚举选项可能保守低估。
- 材料匹配修复静态容量判断，不接管宿主每一步选牌，也不模拟消耗后任意动态技能状态。
- 兵乐概率、借刀公开出杀先验、融合权重仍是启发式；尚未大样本胜率校准或手机性能验收。
- 局面键补齐本轮确认的维度，不序列化所有扩展技能的任意 storage，也不保证任意自定义状态都能被识别。
