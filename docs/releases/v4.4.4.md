# 无名AI v4.4.4 · 性能修复测试版

本次为性能修复测试版，包含源码复审确认的完整性能修复及最终生命周期补修。

- 修复2V2决策中的宿主效果查询与扩展软接管互相重入，避免递归卡死。
- 专项模型恢复不再阻塞公共AI引擎启动，保留恢复、激活和保存竞态保护。
- 面板按需加载，优化v3/v5影子模型加载及主线程调度。
- 护栏计算异常不再伪装为安全通过，保留宿主合法性检查与安全降级。
- 修复更新器、影子模型延迟启动及卸载残留。
- 完善有界启动、决策阶段和长任务诊断。

**Android实机和长时间连续多局稳定性尚未完成全部验收，仍可能存在非递归长任务。本版不宣称所有手机卡顿已经解决。**

模型权重、输入维度、训练标签及来源认证保持不变。

安装：将新的完整客户端ZIP内容解压到独立测试宿主的 extension/无名AI/，确保 extension.js 位于该目录。先备份原扩展与用户存档，不要同时安装两个同名扩展。回退请恢复保存的官方4.4.3客户端包，勿用测试存档覆盖原存档。

正式发布附件中的 SHA256SUMS.txt、MANIFEST.json、RELEASE-RECORD.json 标明实际构建提交、文件清单、模型摘要和安装包校验；安装包来自本次发布提交重新构建，不使用旧QA包。
